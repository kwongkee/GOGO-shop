## 🎮 核心模块详解

### 商城V2 API (`app/ewei_shopv2_api.php`) ⭐

微擎商城V2核心API文件，提供：
- 商品查询/展示 API
- 订单创建/管理 API
- 用户登录/注册 API
- 支付回调处理

### 用户中心 (`app/uc.php`)
- 用户信息管理
- 积分/余额管理
- 收货地址管理

### AccessToken管理 (`app/accesstoken.php`)
- 微信AccessToken获取与缓存
- 接口鉴权管理

## 🛤️ API路由文档

### 商城主入口
| 路径 | 说明 |
|------|------|
| `/index.php` | 微擎框架主入口 |
| `/api.php` | API统一入口 |
| `/app/ewei_shopv2_api.php` | 商城V2专属API |

### 微擎框架路由规则
```
# 前台路由（通过 index.php 路由分发）
/?c=entry&a=entry&do=...&m=ewei_shopv2   # 商城模块入口

# API路由
/api.php?c=...&a=...                     # API接口
/app/ewei_shopv2_api.php?act=...         # 商城V2 API
```

### 主要API端点（推测）
| 参数 | 功能 |
|------|------|
| `act=goods` | 商品相关操作 |
| `act=order` | 订单相关操作 |
| `act=user` | 用户相关操作 |
| `act=cart` | 购物车操作 |
| `act=pay` | 支付相关 |

## 🔧 核心功能模块

### 1. 电商核心功能
- **商品管理**: 商品上下架、分类、规格SKU
- **订单系统**: 订单创建、支付、发货、售后
- **购物车**: 商品加购、结算
- **库存管理**: 实时库存同步

### 2. 会员与营销
- **会员体系**: 等级、积分、余额
- **优惠券**: 创建、发放、核销
- **拼团/秒杀**: 活动营销功能

### 3. 支付集成
- **微信支付**: 小程序/H5支付
- **支付宝**: 移动端支付
- **余额支付**: 平台余额

### 4. 商户管理
- **多商户**: 商户入驻与管理
- **分账**: 平台/商户分账
- **结算**: 商户提现结算
